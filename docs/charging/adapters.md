# Перехідники та адаптери

Вибір правильних перехідників (адаптерів) для Tesla — запорука комфортного життя як у місті, так і в далеких подорожах. Ось що варто знати на основі реального досвіду власників.

!!! question "Питання зі спільноти"
    Які перехідники потрібні для комфортного життя, якщо залишити американський Tesla port?

!!! success "Відповідь"
    Основний набір: 
    1) CCS2 на Tesla для швидких зарядок та Supercharger. 
    2) J1772 на Tesla для повільних американських станцій. 
    3) Type 2 AC на Tesla для повільних європейських зарядок з конектором Type 2. 
    Додатково може знадобитися кабель Type 2 AC на J1772.

!!! question "Питання зі спільноти"
    Чи варто залишати перехідник у розблокованому порту після зарядки?

!!! success "Відповідь"
    Не варто залишати перехідник, адже його можуть витягнути або вкрасти. Завжди забирайте свій кабель та перехідник, коли сесія завершена.

!!! question "Питання зі спільноти"
    Чи можна переробити конектор Type 1 на Type 2 у зарядці EnergyStar?

!!! success "Відповідь"
    Самі представники компанії відмовляються змінювати конектори за гроші, оскільки продають готові рішення. 

!!! question "Питання зі спільноти"
    Що буде, якщо згорить китайський адаптер CCS2 на швидкій зарядці?

!!! success "Відповідь"
    Будь-яка компанія-оператор може вимкнути підтримку сторонніх адаптерів, якщо вони несуть ризики. Рекомендується використовувати перехідники, які пройшли тестування і мають надійну конструкцію.

!!! question "Питання зі спільноти"
    Чи закриває лючок дощ і сніг, коли я заряджаюсь на вулиці? 

!!! success "Відповідь"
    Досвід показує, що за 3 роки заряджання на вулиці з морозами та снігом у порт нічого не потрапляє. Захисні чохли часто намокають і їх неможливо нормально натягнути.
