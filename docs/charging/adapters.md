# Адаптери (Type2, CCS, CHAdeMO)

Вибір правильних перехідників (адаптерів) для Tesla — запорука комфортного життя як у місті, так і в далеких подорожах. Ось що варто знати на основі реального досвіду власників.

Які перехідники потрібні для комфортного життя, якщо залишити американський Tesla port? Основний набір:&#x20;

1\) CCS2 на NACS для швидких зарядок та Supercharger. (найкраще використовувати перехідник українського виробництва "від Павла")

&#x20;2\) J1772 на NACS для повільних "американських станцій".&#x20;

3\) Type 2 AC на NACS для повільних європейських зарядок з конектором Type 2.&#x20;

\*Додатково може знадобитися кабель Type 2 AC на J1772.
