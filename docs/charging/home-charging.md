# Домашня зарядка

## Type 2 (Mennekes) — стандарт для дому

Для домашньої зарядки рекомендується встановити **wallbox** на 11 або 22 кВт з роз'ємом Type 2.

### Скільки кВт дає Type 2?

!!! question "Питання зі спільноти"
    *«Type 2 — 7 кВт на годину дає?»*

!!! success "Відповідь"
    - **Wallbox 1-фазний**: до 7,4 кВт (32А × 230В)
    - **Wallbox 3-фазний 11 кВт**: 3 × 16А × 230В = 11 кВт
    - **Wallbox 3-фазний 22 кВт**: 3 × 32А × 230В = 22 кВт
    
    На специфікації може бути вказано "22 кВт", але реальна швидкість залежить від кабелю та самої станції.

### Американська Tesla + Type 2 адаптер

!!! question "Питання зі спільноти"
    *«Тайп 2 на америку з переходником буде більше 7 кВт видавати?»*

!!! info "Відповідь"
    Залежить від **кабелю та самої станції**. Машина (американська M3/MY) може підтримувати до **48А, ~10 кВт** на AC.
    Але буде обмежена тим, що підтримує стенд.
