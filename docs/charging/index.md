# Зарядка Tesla в Україні

## Огляд варіантів зарядки

| Тип | Потужність | Де |
|-----|-----------|-----|
| Побутова розетка 220В | ~2,3 кВт | Вдома (дуже повільно) |
| Wallbox / Type 2 AC | 7–22 кВт | Вдома або публічні |
| Supercharger V3 | до 250 кВт | Мережа Tesla |
| CCS2 DC | до 150–350 кВт | Публічні IONITY, DTEK та ін. |
