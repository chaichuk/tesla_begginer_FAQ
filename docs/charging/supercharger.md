# Supercharger та швидка зарядка

Заряджання на Tesla Supercharger та станціях Ionity під час подорожей Європою має свої особливості. 

!!! question "Питання зі спільноти"
    Як працює зарядка на станціях Ionity та яку картку прив'язувати?

!!! success "Відповідь"
    Заряджання на Ionity без підписки дуже дороге (близько 10-11 грн за кВт), тому краще використовувати Supercharger. Якщо багато подорожуєте, варто придбати підписку за 19 євро/міс. Для оплати можна використовувати українську картку або картку Wise.

!!! question "Питання зі спільноти"
    Чи можна доїхати до наступного Supercharger, якщо тримати швидкість 120 км/год?

!!! success "Відповідь"
    Усе залежить від ландшафту, погоди та коліс. При швидкості 120 км/год споживання суттєво зростає. Щоб гарантовано доїхати на велику дистанцію, оптимально тримати 90-100 км/год.

!!! question "Питання зі спільноти"
    Чому навігація іноді прокладає маршрут через глухі дороги при пошуку зарядок?

!!! success "Відповідь"
    В Європі штатна навігація Tesla працює відмінно, але в Україні без офіційної підтримки може прокладати маршрути неоптимально. Рекомендується користуватися Waze або Google Maps на паралельному екрані.

!!! question "Питання зі спільноти"
    Яка оптимальна швидкість по трасі для запасу ходу?

!!! success "Відповідь"
    Математично ідеально близько 50 км/год, але це надто довго. Оптимальна швидкість для поїздок — близько 100 км/год. В екстремальних випадках (наприклад, треба проїхати 160 км на 49% заряду) можна їхати 70 км/год.

!!! question "Питання зі спільноти"
    Як шукати швидкі зарядки в Україні, якщо вони не відображаються на екрані Tesla?

!!! success "Відповідь"
    Використовуйте додаток PlugShare для пошуку станцій по маршруту, а також додатки місцевих операторів (GoToU, EcoFactor, Yasno тощо).
