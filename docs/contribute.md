# Як зробити внесок у Wiki

Ця wiki живе завдяки спільноті. Якщо ви знаєте відповідь на питання або хочете виправити помилку — зробити це дуже просто. Не потрібні технічні знання!

---

## 3 прості кроки

### Крок 1: Натисніть "Редагувати сторінку" ✏️

На кожній сторінці wiki у **правому верхньому куті** є кнопка з іконкою олівця (✏️).
Натисніть на неї — вона відкриє цю сторінку прямо на GitHub для редагування.

!!! info "Перший раз?"
    GitHub попросить вас **зареєструватися** (безкоштовно). Це займе 2 хвилини.

---

### Крок 2: Відредагуйте текст 📝

GitHub відкриє редактор тексту прямо в браузері.

- Текст написаний у форматі **Markdown** — це просто текст з деякими символами для форматування
- Ви побачите кнопку **Preview** — натисніть, щоб перевірити як буде виглядати результат

**Базовий Markdown:**

```
**жирний текст**
*курсив*
# Великий заголовок
## Менший заголовок
- Пункт списку
```

---

### Крок 3: Запропонуйте зміни 🚀

Прокрутіть вниз до блоку **"Propose changes"**:

1. Напишіть коротко, що ви змінили (наприклад: *"Додав інфо про зарядку на Оболоні"*)
2. Натисніть зелену кнопку **"Propose changes"**
3. На наступній сторінці натисніть **"Create pull request"**

Готово! 🎉 Адміністратори перевірять ваші зміни і додадуть їх на сайт.
