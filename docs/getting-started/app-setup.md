# Налаштування додатку Tesla

## Як додати авто в додаток?

!!! question "Питання зі спільноти"
    *«Є ли у кого під рукою інструкція додавання авто через сайт?»*

Є два способи:

### Спосіб 1: Через додаток
1. Завантажте додаток [Tesla](https://www.tesla.com/app)
2. Зареєструйте або увійдіть в акаунт Tesla
3. Натисніть «+» → «Додати автомобіль»
4. Введіть VIN-номер вашого авто

### Спосіб 2: Через сайт
Відеоінструкція: [youtube.com/watch?v=zQEPFxFpfE4](https://youtu.be/zQEPFxFpfE4)

## WiFi вимикається при переключенні на Drive

!!! question "Питання зі спільноти"
    *«До кого можна звернутися, щоб WiFi не вимикався при переключенні на Drive?»*

!!! info "Відповідь"
    Через варшавський офіційний сервіс роблять **дистанційно**, вартість до **200$**.

    Контактуйте з Tesla Support → попросіть зв'язати з Варшавою (Польща).

---

## LTE в автомобілі

!!! question "Питання зі спільноти"
    *«В машині LTE працює?»*

!!! success "Відповідь"
    Так, LTE вбудований. Для повноцінної роботи деяких функцій потрібен **LTE в машині + Bluetooth на телефоні**.
