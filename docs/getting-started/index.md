# Огляд

Придбали Tesla? Ось найважливіші речі, які потрібно зробити в першу чергу.

## Контрольний список нового власника

* Завантажити [додаток Tesla](https://www.tesla.com/app) (iOS / Android)
* Зареєструвати авто в додатку або переоформити від попереднього власника
* Налаштувати домашню зарядку або знайти публічну зарядну станцію
* Ознайомитися з базовими функціями
