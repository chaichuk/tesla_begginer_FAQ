# Порт зарядки Model 3

## Визначення типу порту

Відкрийте ліву задню дверцю — порт зарядки знаходиться в задній лівій чверті кузова.

- **Кругла форма з 5 контактами** = Tesla (американська, старіші моделі)
- **Трикутна форма Type 2** = Європейська Model 3

## Зарядка на Supercharger з CCS адаптером

!!! question "Питання зі спільноти"
    *«Через переходник — порт американський. На V3 суперчарджерах, які швидші — тільки CCS2 роз'єми»*

!!! success "Відповідь"
    З офіційним адаптером Tesla CCS → досягається **до 140 кВт** максимально.
    Перехідник може нагріватися при тривалій зарядці — це нормально.
