# Tesla Model 3

## Основні версії

Tesla Model 3 постачається в двох версіях залежно від ринку:

| Параметр | 🇺🇸 Американська | 🇪🇺 Європейська |
|----------|-----------------|----------------|
| Порт зарядки | J1772 (AC) + CCS1 (DC) | Type 2 (AC) + CCS2 (DC) |
| Supercharger | Використовує Proprietary → CCS1 | Використовує CCS2 |
| Зарядка AC | до 48А, ~11 кВт | до 48А, ~11 кВт |
| Зарядка DC | до 250 кВт (V3) | до 250 кВт (V3) |
