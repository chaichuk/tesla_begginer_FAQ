# Model 3: США vs Європа

## Головна відмінність — порт зарядки

Найважливіша практична відмінність між американською та європейською Tesla — **стандарт зарядного порту**.

### Американська Model 3 (до 2024 року)

- **AC зарядка**: роз'єм J1772 (або через адаптер)
- **DC швидка зарядка**: CCS1 (North American CCS)
- **Supercharger**: спочатку власний Tesla роз'єм, але зараз вже CCS1

### Європейська Model 3

- **AC зарядка**: Type 2 (Mennekes) — стандарт в Україні та ЄС
- **DC швидка зарядка**: CCS2 (European CCS)
- **Supercharger**: CCS2 — сумісний з мережею V3 без адаптеру

---

## Що це означає для України?

!!! warning "Важливо для власників американських авто"
    В Україні **більшість** публічних зарядних станцій мають **Type 2 та CCS2** роз'єми (євростандарт).
    
    Якщо у вас **американська** Tesla — вам потрібен **адаптер CCS1 → CCS2** для DC зарядки
    та **J1772 → Type 2** для AC зарядки.

Детальніше про адаптери: [Адаптери для зарядки](../charging/adapters.md)

## Максимальна ширина шини на 18" дисках (Model 3)

!!! question "Питання зі спільноти"
    *«Яка максимальна ширина шини стане на 18 радіус на M3?»*

!!! info "Відповідь зі спільноти"
    Стандарт: **235/45 R18**. Деякі власники ставлять ширші — залежить від конкретного диску та кліренсу.
    Рекомендуємо запитати в чаті з конкретними параметрами вашого диску.
