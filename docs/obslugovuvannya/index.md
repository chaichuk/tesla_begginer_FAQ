# Огляд

## Tesla не потребує традиційного ТО

На відміну від авто з ДВЗ, Tesla **не потребує**:

* ❌ Заміни моторного масла
* ❌ Заміни антифризу
* ❌ Заміни масла редуктора

**Але потрібно** регулярно замінювати:

* ✅ Фільтр салону (кожні 2 роки або при появі запаху)
* ✅ Гальмівна рідина (кожні 2 роки)
* ✅ Шини (за зносом)
