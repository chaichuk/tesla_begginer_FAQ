# Діагностика та помилки Tesla

## Стандартний перезапуск системи

Якщо щось пішло не так — перший крок:

!!! tip "Soft reset (перезавантаження дисплею)"
    Утримуйте **обидві кнопки на кермі** (~10 секунд) до появи логотипу Tesla.
    Машина не зупиняється, можна робити на ходу.

!!! tip "Full reboot (повне перезавантаження)"
    Машина заблокована → затисніть **обидві кнопки + педаль гальма** (~10 секунд).

---

## Помилки на дисплеї — що означають?

!!! question "Питання зі спільноти"
    *«Машина плине з США, її треба стартувати і робити всі перепрошивки»*

!!! info "Відповідь зі спільноти"
    Все залежить від пошкоджень після аукціону:
    
    - **Просто прикурити і зарядити** — якщо авто просто розрядилося
    - **Поміняти піропатрон у батареї** — якщо спрацювала пасивна безпека (подушки)
    - **Перепрошивка** — для розблокування регіональних функцій або після серйозного ремонту

## Додатки для діагностики

| Додаток | Платформа | Що показує |
|---------|-----------|-----------|
| **Stats for Tesla** | iOS | Деградація батареї, ефективність, детальна статистика |
| **TeslaFi** | Веб | Пробіг, зарядки, трекінг |
| **Tessie** | iOS/Android | Статистика, автоматизація |

## Перевірка прошивки

Поточну версію прошивки дивіться: **Авто → Програмне забезпечення**.

Для відстеження нових версій: [teslafi.com/firmware](https://www.teslafi.com/firmware.php)
