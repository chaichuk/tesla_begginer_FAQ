# Дзеркала

### Як відрізнити оригінальні європейські дзеркала від американських?

**💡 Відповідь:** Європейські дзеркала мають асферичну (або сферичну) форму, що зменшує сліпі зони. Американські — плоскі, через що огляд значно гірший.

### Чи можна замінити лише скельця дзеркал, чи треба міняти весь корпус?

**💡 Відповідь:** Можна замінити лише самі скельця на європейські (асферичні). Вони легко знімаються за допомогою пластикової лопатки, головне не пошкодити контакти підігріву.

### Чи варто клеїти атермальну плівку на панорамний дах?

**💡 Відповідь:** Плівка не вирішує проблему сильного нагріву повністю. Більшість власників рекомендує використовувати спеціальні сонцезахисні шторки-сітки, які встановлюються під дах у літній період.

### Яку плівку обрати для лобового скла?

**💡 Відповідь:** Кращі варіанти: 3M Crystalline, SunTek Evolve, LLumar. Вони є багатошаровими атермальними плівками. В середньому топові матеріали коштують 170-300 доларів за лобове скло.
